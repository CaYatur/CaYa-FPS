# CaYa FPS (2024)

2024 · Botlu ve çok oyunculu FPS oyunu (Unity, Netcode). Kaynak, derlemeden geri kazanıldı.

Unity ile yaptığım FPS oyunu:

- Devriye gezen, siper alan ve zorluk seviyeli düşman botları (`EnemyAI.cs`)
- Unity Netcode ile çok oyunculu mod, host/katılım ekranları, oyun içi sohbet
- Can, ateş, hız güçlendirmesi, duraklatma ve hassasiyet ayarları
- 6 sahne: Ana menü, Normal oyun, Çok oyunculu, DeadWar, Trainer, test
- Modeller Blender ile kendi tasarımım

> **Kurtarılan kaynak:** Bu projenin orijinal kaynak kodu zamanla kayboldu. 2026'da elimde kalan Windows derlemesinden (24 Temmuz 2024) AssetRipper ile geri kazanıldı.
